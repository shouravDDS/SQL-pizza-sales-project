# SQL-pizza-sales-project
Just Completed a Hands-On SQL Project! 🍕

I recently completed an end-to-end SQL project using a pizza sales dataset, covering everything from basic queries to advanced analytical techniques. This project helped me deepen my understanding of SQL through real-world business scenarios.

📈 Built advanced queries for cumulative revenue and ranked insights using window functions.

📚 Skills demonstrated:

Joins and aggregations

Window functions

Subqueries and common table expressions (CTEs)

Data-driven decision making

This project was both challenging and rewarding—perfect for sharpening my SQL and data analysis skills.
